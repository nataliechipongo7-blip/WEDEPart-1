 1. Project Overview & Objectives
Candice Cakes is a home-based bakery specializing in custom, affordable celebration cakes. This project transitions the business from temporary WhatsApp messages to a permanent digital storefront.

* 24/7 Visibility & Lasting Portfolio: Displays high-quality cake galleries permanently.
* Time-Saving Automation: Uses a clean HTML Menu Table to answer repetitive pricing and flavour questions.
* Structured Enquiries: Features a dedicated Form to capture dates, themes, and allergies.

---

 2. Design System & Aesthetic
To mirror an authentic, premium home-baked feel, the following design constraints were implemented using CSS:
- Color Palette: Rose Brown (Headings/Nav), Soft Pink (Highlights), and Seashell (Background).
- Typography: Playfair Display for elegant headings; Cambria for clear, comfortable reading text.
- Mobile-First Approach: Elements stack natively on mobile screens with large, thumb-friendly buttons to streamline one-handed use.
