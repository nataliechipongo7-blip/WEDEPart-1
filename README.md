Project Overview
As outlined in my project proposal, Candice-Cakes is a small, home-based bakery located in Gugulethu, Cape Town, that focuses on creating custom cakes. Right now, the business relies heavily on WhatsApp Business for communication, but it lacks a permanent home for business information, and cake photos disappear after twenty-four hours.
This project aims to build a permanent digital storefront that keeps the bakery visible 24/7. It offers a personal, high-quality alternative to mass-produced retail cakes, making special occasions memorable while maintaining an authentic, home-baked quality for local families and budget-conscious shoppers in the neighborhood.
Website Goals and Objectives
Goals:
 24/7 Visibility: Build a permanent digital storefront to keep the business visible around the clock.
 Permanent Portfolio: Create a professional, lasting gallery so high-quality cake photos don't disappear.
 Save Time: Reduce the time the baker spends answering repetitive, basic questions about prices and flavors.
 Better Organization: Streamline the ordering process so important details like event dates, themes, and allergy issues don't get lost in chat messages.
Objectives:
 Use a clear HTML table so customers can instantly see all affordable pricing options.
 Build a functional Enquiry Form to easily capture all order details in one go.
 Ensure a fully responsive layout so mobile users can easily place orders right from their phones.
Key Features and Functionality--
 Homepage: A clean landing page featuring a high-quality photo of a cake and a clear "Order" button.
 About Us: A section telling the story of the bakery to give it a personal, welcoming feel.
 Menu and Prices: A structured HTML table breaking down flavors, sizes, and affordable pricing.
 Permanent Gallery: A dedicated space showing past work so customers can verify the quality of the cakes.
 Enquiry Form & Contact: A structured form to collect order dates, themes, and allergy details, along with the baker's direct contact details.
Design and User Experience--
I have implemented the exact design specifications from my proposal to give the site a cohesive brand look:
 Color Scheme: Rose brown for some headings, Soft Pink for highlights, and a clean Seashell background.
 Typography: Playfair Display for large, elegant headings and Cambria for easy-to-read body text.
 Layout Approach: A simple, mobile-first design that still looks great on a laptop, using easy top navigation and big buttons so it's simple for everyone to use.
